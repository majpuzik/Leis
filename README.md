## What this document is — and is not (claims boundary) / Co tento dokument je a co není

The LEIS Constitution is a **normative constitution of principles**, written with the conventions **MUST / SHOULD / MAY**. It describes how a preservation-and-cognition system *ought* to behave.

It is **not**, and must not be read as, a claim that the systems it describes — autonomous survival, self-reconstructing seeds, a live federated cryptographic network, universal or substrate-independent cognition — are a verified, operational, benchmarked reality. Those are **aspirational normative goals, not evidence**.

Per the Constitution's own epistemology — **V.6 Evidence Before Opinion** and **V.10 Intellectual Humility** — aspiration must never be silently merged with evidence. For what is actually implemented and independently conformance-tested, see the **evidence-bounded public release** *LEIS Portable Kernel v3.0.1* and its explicit *claims boundary* at **https://github.com/MartinPuzik/LEIS-WEB** (98/98 deterministic local protocol cases, with its own `non_claims`).

*Ústava je normativní soustava principů (MUST/SHOULD/MAY), ne tvrzení, že popsaná autonomní síť, sebe-rekonstrukce či univerzální kognice jsou ověřená, funkční realita. To, co je skutečně implementované a nezávisle otestované, je v evidence-bounded vydání v3.0.1 (MartinPuzik/LEIS-WEB).*
